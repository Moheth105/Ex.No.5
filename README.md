# EXP 5: Comparative Analysis of Different Types of Prompting Patterns Using Multiple Test Scenarios

## Aim

To test and compare how different prompting patterns influence the responses generated by an AI language model. The experiment evaluates the difference between **naïve or broad prompts** and **basic,clear,and refined prompts** across multiple scenarios.

The generated responses are analyzed based on **quality,accuracy,relevance,clarity,completeness,depth,and adherence to instructions**. The experiment also investigates whether providing additional context and structure consistently improves the performance of an AI model.

---

## Objectives

The major objectives of this experiment are:

* To understand the importance of prompt engineering in Generative AI.
* To identify the differences between naïve and structured prompting.
* To study how prompt clarity affects AI-generated responses.
* To compare the quality of responses generated from different prompt patterns.
* To evaluate the factual accuracy and relevance of generated responses.
* To analyze the depth and completeness of AI-generated answers.
* To determine whether detailed prompts consistently produce better results.
* To identify scenarios where simple prompts are sufficient.
* To understand how additional context and constraints influence AI responses.
* To develop effective prompting techniques for obtaining reliable and useful outputs.

---

# Introduction

Generative Artificial Intelligence systems such as ChatGPT are capable of generating text,answering questions,summarizing information,providing recommendations,writing stories,and performing many other language-based tasks.

However,the quality of the output does not depend only on the capability of the AI model. The way the user communicates the requirement to the model also has a significant impact on the generated response.

This communication is performed through a **prompt**.

A prompt is an instruction,question,or description provided to an AI model to obtain a desired response. A simple prompt may provide only the basic task,while a structured prompt can provide additional information such as:

* Background context
* Specific instructions
* Expected output format
* Target audience
* Length requirements
* Constraints
* Examples
* Evaluation criteria
* Tone and style

For example,the prompt:

> Explain machine learning.

is relatively broad. The model has to determine what information should be included,how detailed the explanation should be,and what level of technical knowledge the user has.

A more structured prompt could be:

> Explain machine learning to a first-year engineering student. Define machine learning,describe its three major types,provide one practical example for each type,and conclude with a short comparison. Use simple language and headings.

The second prompt provides significantly more guidance to the model.

This experiment investigates whether this additional structure results in measurable improvements in the generated output.

# Prompting Patterns Used

The experiment primarily compares two prompting patterns.

## 1. Naïve Prompt

A naïve prompt is a basic,broad,or minimally specified instruction.

It generally contains only the task that needs to be performed without providing extensive context or output constraints.

### Characteristics

* Short
* General
* Minimal context
* Few or no constraints
* No specific output structure
* Leaves many decisions to the AI model

### Example

```text
Explain artificial intelligence.
```

The model must determine:

* What definition to provide
* How much detail to include
* Which concepts to discuss
* Who the explanation is intended for
* What format should be used

---

# 2. Basic / Refined Prompt

A basic or refined prompt provides clearer instructions and additional context to guide the AI model toward a desired result.

### Characteristics

* Clear objective
* Relevant context
* Specific instructions
* Defined audience
* Desired response structure
* Output constraints
* Expected level of detail

### Example

```text
Explain artificial intelligence to a beginner engineering student.
Start with a simple definition,then explain its major applications,
advantages,and limitations. Include at least three real-world examples.
Use simple language and organize the response using headings and bullet points.
```

The model now has much clearer information about what is expected.

# Experimental Methodology

The experiment is performed using multiple test scenarios representing different types of real-world AI usage.

Each scenario contains two prompts:

### Prompt A — Naïve Prompt

A short and relatively unstructured request.

### Prompt B — Basic Prompt

A refined version of the same request containing additional instructions and context.

The task itself remains the same in both cases.

The generated responses are then compared.

---

# Experimental Procedure

## Step 1: Select a Test Scenario

Choose a task that can be performed using a Generative AI model.

Examples include:

* Creative writing
* Factual question answering
* Concept explanation
* Summarization
* Recommendation
* Comparison
* Problem solving
* Email generation
* Technical explanation
* Educational content generation

---

## Step 2: Create the Naïve Prompt

Write a short and broad prompt without adding extensive instructions.

Example:

```text
Write a story about a robot.
```

---

## Step 3: Create the Basic Prompt

Refine the same prompt by adding useful instructions.

Example:

```text
Write a 500-word science-fiction story about a service robot
that develops emotions while helping an elderly person.
Use simple but engaging language. Include a clear beginning,
conflict,and ending. Make the story suitable for teenagers.
```

---

## Step 4: Execute Both Prompts

Enter both prompts separately into ChatGPT.

The generated outputs should be recorded without manually modifying them.

---

## Step 5: Evaluate the Responses

Each response is evaluated using predefined criteria.

The main criteria are:

1. Quality
2. Accuracy
3. Relevance
4. Clarity
5. Completeness
6. Depth
7. Instruction adherence

---

## Step 6: Compare the Results

The responses generated from the naïve and basic prompts are compared.

The experiment should identify:

* Which response is more useful?
* Which response follows instructions better?
* Which response provides greater detail?
* Which response is more accurate?
* Which response is easier to understand?
* Whether additional prompting improves the output significantly.

# Evaluation Criteria

## 1. Quality

Measures the overall usefulness and quality of the response.

Questions to consider:

* Is the response well written?
* Is the information presented logically?
* Is the response useful to the user?
* Does the answer appear polished?

---

## 2. Accuracy

Measures whether the information provided is correct.

Questions to consider:

* Are factual statements correct?
* Are technical explanations accurate?
* Does the response contain misleading information?
* Does the generated code satisfy the requirements?

---

## 3. Relevance

Measures how closely the response addresses the requested task.

A response can be detailed but still have low relevance if it contains unnecessary information.

---

## 4. Clarity

Measures how easy the response is to understand.

Factors include:

* Language simplicity
* Organization
* Sentence structure
* Headings
* Examples
* Logical flow

---

## 5. Depth

Measures how thoroughly the response addresses the topic.

A high-depth answer should provide:

* Appropriate explanation
* Relevant examples
* Supporting details
* Important considerations
* Meaningful conclusions

---

## 6. Completeness

Measures whether all requested parts of the task are addressed.

For example,if a prompt asks for:

* Definition
* Three examples
* Advantages
* Limitations

the response should contain all four components.

---

## 7. Instruction Adherence

Measures whether the AI follows the explicit requirements in the prompt.

For example:

```text
Write the answer in 150 words.
```

If the generated answer is significantly longer,it may receive a lower instruction-adherence score.

# Qualitative Analysis

Apart from numerical scoring,the responses should also be analyzed qualitatively.

## Observation 1: Prompt Clarity

Naïve prompts give the model greater freedom to interpret the task. This can be useful for creative tasks,but it may also result in inconsistent outputs.

Basic prompts reduce ambiguity by explicitly communicating the user's requirements.

---

## Observation 2: Response Structure

When the prompt specifies an expected format,the generated response is generally more structured.

For example:

```text
Present the answer in a table.
```

Defining the target audience can significantly influence the complexity of the response.

For example:

encourages simpler terminology,while:

```text

```

allows the model to use more technical terminology.

---

## Observation 4: Constraints

Explicit constraints can improve consistency.

Examples include:

* Word limits
* Number of examples
* Required sections
* Output format
* Programming restrictions
* Tone requirements

---

## Observation 5: Depth of Response

Broad prompts may result in either very short or unnecessarily broad responses.

Adding explicit requirements for explanation depth helps control the level of detail.

# Does a Basic Prompt Always Perform Better?

Not necessarily.

The experiment should not assume that a more detailed prompt is always superior.

For very simple tasks,a naïve prompt may already contain enough information.

For example:

```text
What is 10 + 20?
```

does not require a highly structured prompt.

Adding excessive instructions such as:

```text
Act as a mathematics professor...
Explain the mathematical reasoning...
Provide multiple methods...
Discuss the historical development...
```

would introduce unnecessary complexity for a simple calculation.

Therefore,the effectiveness of prompt structure depends on the complexity of the task.

---

# Situations Where Naïve Prompts May Work Well

Naïve prompts can be effective when:

* The task is simple.
* The expected output is obvious.
* There are very few possible interpretations.
* Creativity is desired.
* The user wants the AI to make independent decisions.
* No specific format is required.

Example:

```text
Give me a motivational quote.
```

A highly detailed prompt is not necessarily required.

---

# Situations Where Basic Prompts Are More Effective

Structured prompts are particularly useful when:

* The task is complex.
* Multiple requirements must be satisfied.
* A specific format is required.
* The response must target a particular audience.
* Technical accuracy is important.
* The output has strict constraints.
* The user needs reproducible results.
* The AI must perform multiple steps.

Example:

```text
Analyze the following technical problem...
Identify the root cause...
Suggest three possible solutions...
Compare the solutions based on cost,complexity,and reliability...
Recommend the most appropriate solution...
```

This type of task benefits significantly from structured prompting.

# Factors That Influence Prompt Quality

Several factors can improve the effectiveness of a prompt.

## 1. Context

Providing relevant background information helps the model understand the situation.

## 2. Specificity

Specific instructions reduce ambiguity.

## 3. Constraints

Constraints control the output.

## 4. Role or Perspective

Specifying an appropriate role can help establish the desired level of expertise.

Example:


## 5. Output Format

Defining whether the answer should be a:

* Table
* List
* Paragraph

* Code block
* Report

## 6. Examples

Providing examples can help communicate the expected output pattern.

## 7. Target Audience

Specifying the audience helps control vocabulary and complexity.

# Recommended Prompt Structure

A practical structured prompt can follow the format:

```text
ROLE
+ 
CONTEXT
+
TASK
+
CONSTRAINTS
+
OUTPUT FORMAT
+
EXPECTED RESULT
```

### Example

```text
Role:
Act as a technical educator.

Context:
The reader is a first-year engineering student.

Task:
Explain the concept of machine learning.

Constraints:
Use simple terminology and avoid advanced mathematics.
Include three real-world examples.

Output Format:
Use headings,bullet points,and a comparison table.

Expected Result:
The explanation should allow a beginner to understand
the basic concept within five minutes.
```

This structure makes the intended task significantly clearer.

# Limitations of the Experiment

Although prompt engineering can significantly improve AI responses,the experiment has certain limitations.

### 1. Subjective Evaluation

Quality and depth can sometimes be subjective. Different evaluators may assign different scores.

### 2. Model Dependence

Different AI models may respond differently to the same prompt.

### 3. Response Variability

Generative AI systems may produce different responses even when the same prompt is used.

### 4. Prompt Bias

A highly detailed prompt may unintentionally restrict the model's creativity.

### 5. Limited Test Scenarios

A small number of test scenarios cannot represent every possible use case of Generative AI.

### 6. Factual Verification

AI-generated factual information should be independently verified when accuracy is critical.

---

# Best Practices Identified

Based on this experiment,the following prompting practices are recommended:

### Be Clear

State exactly what needs to be done.

### Provide Context

Include only the background information relevant to the task.

### Specify the Audience

Mention whether the output is intended for a beginner,student,engineer,manager,or another audience.

### Define the Output Format

Specify whether the output should be a table,list,paragraph,code,or step-by-step explanation.

### Add Useful Constraints

Specify requirements such as:

* Length
* Number of examples
* Required sections
* Technical level
* Tone

### Avoid Unnecessary Information

More words do not automatically mean a better prompt.

### Use Examples When Necessary

Examples can be particularly useful when the desired output format is difficult to describe.

# Conclusion

This experiment demonstrates the importance of prompt engineering when interacting with Generative AI systems.

A naïve prompt provides minimal information and allows the AI model to interpret the task independently. This approach can be effective for simple questions and open-ended creative tasks. However,when a task contains multiple requirements,technical constraints,or a specific expected output,the lack of structure can lead to inconsistent or incomplete responses.

A basic or refined prompt provides additional context,instructions,constraints,and output requirements. This generally improves the relevance,clarity,completeness,and predictability of the generated response.

The experiment also demonstrates that **more detailed prompting is not automatically better**. The appropriate level of prompting depends on the complexity of the task. Simple tasks may require only a short instruction,while complex tasks benefit from carefully structured prompts.

Therefore,the key principle of effective prompt engineering is:

> **Provide enough information to eliminate ambiguity while avoiding unnecessary constraints.**

Effective prompting allows users to communicate their requirements more precisely and obtain more useful,consistent,and task-specific results from Generative AI systems.
